# User-facing safety notice — developer alpha

AFK Sentinel is not a tamper-proof security product, burglar alarm, intruder identifier, or substitute for disk encryption. It cannot monitor when a laptop sleeps or is powered off. A user with privileged access or an attacker using the same Linux account can disable the program and alter local recordings. Motion detection may produce false positives and miss real events. The current developer alpha does not send alerts or provide a live viewer.

Webcam recording may affect other people. Use only where you have the legal right to record, respect informed consent and local privacy laws, and avoid deployment in shared or sensitive spaces without appropriate notice.

Store recordings in a private directory and set a lawful retention policy before any unattended deployment. No automated retention deletion is included in this release.
