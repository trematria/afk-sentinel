# Contributing

Thank you for helping build a privacy-conscious Linux security application.

- Run `PYTHONPATH=src python3 -m unittest discover -s tests -v` before suggesting changes.
- Preserve `stream_port 0` and `webcontrol_port 0` in this local-only alpha.
- Propose security-sensitive network, camera or deletion behaviour behind separate opt-in gates.
- Include tests for new behavior and document exact Ubuntu/GNOME versions.
- Never submit footage, real home directory paths, credential material or private device tokens.
- Do not claim universal Linux support until it has been tested.
