# Security policy

**Status:** v0.1.0-alpha is a developer preview, not a supported security appliance.
Do not run this source alongside a separate AFK Sentinel camera controller on the same machine.

Please report security issues privately to the repository maintainer through GitHub private
vulnerability reporting once the repository is published (if enabled); otherwise use the
maintainer's published security contact. **Never attach recordings, private credentials,
access tokens, camera frames or personal identifiers to public issues.**

No undisclosed third-party cloud services are bundled. Remote push and live view are future
work and must undergo security review before being enabled.
